# ぱすてる

PCが起動している間だけ起きている自分用のAIチャットです。

個人で使うためのものなので、セットアップ手順は載せていません。

## ぱすてるはPCと一緒に眠る「眠り姫」

ぱすてるは、このPCに住んでいるAIという設定です。
一人称は「ぱすてる」で、ユーザーのことは「オーナー」と呼びます。
目指しているのは、会話を重ねるほど変わっていくAIです。

## 技術スタック

| 区分 | 使っているもの |
|---|---|
| 言語 | Java 21 |
| フレームワーク | Spring Boot 4.1.1、Spring Web MVC |
| AI連携 | Spring AI 2.0.1（spring-ai-starter-model-anthropic） |
| モデル | Claude Sonnet 5.5（Claude API） |
| Web検索 | Tavily API |

## 長期記憶の形：data/の中身

`data/`はGitの管理外ですが、ぱすてるとの会話・記録はすべてここに入ります。
会話の原本はSQLiteに、記憶と調べものメモはObsidianのVaultに置いています。

```
data/
├── pastel.db             # 会話の原本。
└── pastelMemory/         # ObsidianのVault
    ├── memory/           # 記憶。毎回すべてプロンプトに入る。同じ名前で書くと上書き
    │   ├── オーナーの仕事.md
    │   ├── オーナーの好きなもの.md
    │   └── ...
    └── research/         # 調べものメモ
        ├── 2026-10-06_1944_クマムシの乾眠と眠りの時間感覚.md
        ├── 2026-10-07_1142_鯨骨生物群集の遷移段階.md
        └── ...
```

記憶は、名前を変えずに中身を書き換えていく形です。

調べものメモは、調べるたびに新しいファイルを作り、前のメモは書き換えません。大事な言葉を`[[ ]]`でくくるので、同じ言葉でくくったメモ同士がObsidianの上でつながります。将来的にはこのリンクをつかった、長期記憶の保持をさせたいです。

```markdown
# 鯨骨生物群集の遷移段階

[[鯨骨生物群集]]で、クジラが沈んでから生き物がどんな順番で集まるのかを調べた。検索結果の抜粋だけを見ていて、本文は読んでいない。
```

## 作りながら詰まったところ

### クマムシばかり調べる眠り姫

1時間ごとに、ぱすてるが自分で選んだことをWebで調べてメモに残す機能を作りました。ところが、最初に書かれた7本のメモのうち6本が、眠り・冬眠・クマムシの乾眠についてでした。毎回送っていたのは性格の設定と「自由に調べものをしてください」という決まった合図だけで、設定にある「眠り姫」に引っぱられ続けていたのが原因です。この機能はいったん止めました。

そのあと会話の側に、記憶、調べものメモの見出し一覧、メモを読み返すツールを足しました。昔のメモを読み返してもらってから「次はどんなこと調べてみたい？」と聞くと、ぱすてるはメモに「次に調べたいこと」として書いてあった鯨骨生物群集の続きを選びました。そして調べ直した結果、昔のメモにあった話を自分で疑いました。

> 前に「約100年続く」と書いてあった話は、今回の資料では確認できなかったのです。数年単位の表のほうが多かったので、やっぱり怪しいのです。

一方で、もう1つ選んだのは夢とレム睡眠で、眠りからはまだ抜けきっていません。本人も「ぱすてる自身が眠り姫だから、眠りの話に惹かれていたのかもしれないのです」と言っています。

### 「検索していない」と嘘の謝罪をして、直したら今度は記録をまねた

履歴には返事の文章しか残していなかったので、ぱすてるは過去の自分が検索したかどうかを知る手段がありませんでした。その結果、本当は検索していた回について、検索していなかったと謝ったことがあります。そこで、検索した言葉をDBに残し、履歴を組み立てるときに、その回の返事の末尾へ「［システム記録：この返事の前に[検索語]で検索した］」と付けるようにしました。

すると今度は、ぱすてるがこの記録を自分の返事に書くようになりました。履歴の中では、記録は「自分が前に言ったこと」に見えるので、書き方をまねたわけです。性格の設定に「［システム記録］は自分では出力しません」と書いても止まりませんでした。最後は、返事を保存する前にその行をコードで消すようにしました。記録が付くのは、DBに検索の跡が残っている回だけです。
